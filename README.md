# AI Fan Avatar MVP
Прототип для создания контента голографического вентилятора CREPESS300 с AI-аватаром.

## Описание
Этот проект позволяет генерировать видеоролики с говорящим AI-аватаром, оптимизированные под круглый экран голографического вентилятора (диаметр 1024px, 1:1 aspect ratio).

## Функционал
- Ввод текста для аватара.
- Симуляция генерации видео (интеграция с HeyGen API в будущем).
- Предпросмотр в круглой маске.
- Подготовка MP4 для загрузки на microSD.

## Железо
- **Модель:** CREPESS300 (или аналоги на 4 лопасти).
- **Разрешение:** 1024x600 (интерполяция до 1024x1024).
- **Загрузка:** microSD / Wi-Fi (через .bin конвертер).

## Установка и запуск (Local)
1. `npm install`
2. `node server.js`
3. Открыть `http://localhost:3000`

## Интеграция с HeyGen API

### Получить API ключ
1. Зайдите на [app.heygen.com](https://app.heygen.com/)
2. Settings → API → Generate API Key
3. Ключ имеет формат: `eyJhb...` (длинная JWT-строка)

### Как работает прототип
1. Введите API ключ — автоматически загрузятся доступные аватары через `GET /v2/avatars`
2. Выберите аватар из списка
3. Введите текст для озвучки
4. POST `/v2/video/generate` с разрешением 1024x1024 (1:1)
5. Поллинг `GET /v1/video_status.get` каждые 5 секунд до статуса `completed`
6. Скачать MP4 и залить на microSD CREPESS300

### Стоимость генерации
- **Free plan:** 1 мин. видео / месяц бесплатно
- **Creator ($29/мес):** 15 мин. видео / месяц
- Для вахты (5–7 роликов по 15 сек) хватит Free plan
